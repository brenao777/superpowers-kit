# Запуск скилла в новом чате

Прикрепите этот архив к новому чату Codex или Claude Code и отправьте ровно этот текст:

```text
В приложенном архиве находится onboarding-скилл Obsidian + Git + GitHub.
Распакуй архив, прочитай SKILL.md и выполни его как инструкцию в этом чате.
Проведи меня от создания нового локального Obsidian vault до приватного GitHub-репозитория, правил AGENTS.md и CLAUDE.md и финальной проверки. Устанавливай Git и GitHub CLI, если их нет; перед каждым изменением кратко говори, что сделаешь. Не требуй MCP и не удаляй файлы.
```

В текущем чате агент сможет следовать `SKILL.md` сразу после распаковки. Для будущих чатов он может установить пакет в `~/.codex/skills/` для Codex или `~/.claude/skills/` для Claude Code.
