# Настройка vault и GitHub

## Минимальная структура

Если пользователь ещё не создал vault, создай указанную им локальную папку. Затем создай только недостающие папки в её корне. После этого пользователь один раз выбирает эту папку в Obsidian через **Open folder as vault**.

Создавай только недостающие папки в корне vault:

```text
Входящие/
Заметки/
Гайды/
```

Не добавляй дополнительные уровни, теги или шаблоны без запроса. Папка `Входящие/` хранит сырьё, `Заметки/` — переработанные материалы, `Гайды/` — инструкции для людей.

## До первого коммита

Сначала создай или дополни `.gitignore` следующими строками:

```gitignore
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.obsidian/graph.json
.trash/
.DS_Store
Thumbs.db
```

Не исключай всю `.obsidian/`: настройки и список плагинов должны приезжать вместе с vault. Если один из игнорируемых файлов уже отслеживается, объясни это и предложи аккуратно убрать его из индекса без удаления с диска.

## Git и GitHub

1. Проверь наличие Git и авторизацию GitHub CLI. Если что-то отсутствует, объясни простыми словами, зачем это нужно, и проведи пользователя через установку или вход.
2. Инициализируй репозиторий только в подтверждённом корне vault.
3. Проверь рабочее дерево перед первым коммитом; не включай секреты и неожиданные крупные файлы.
4. Создай новый приватный репозиторий и отправь содержимое vault.
5. Проверь удалённый репозиторий и покажи, что нужные файлы попали в него, а игнорируемые — нет.

## Автосинхронизация

Для Obsidian Git рекомендуй авто-коммит раз в 5–10 минут и включённый `Pull on startup`. Не называй это мгновенной синхронизацией: изменения появляются на других устройствах после commit/push и следующего pull.

## Проверка готовности

- Новая заметка появляется в приватном репозитории после интервала синхронизации.
- Web Clipper сохраняет страницу в `Входящие/`.
- Агент может перечислить и кратко описать файлы во `Входящие/`.
- Агент создаёт тестовую заметку во `Входящие/`, не изменяя существующие заметки.
- `.obsidian/workspace.json` отсутствует в репозитории.
