# Общая политика для AGENTS.md и CLAUDE.md

Используй этот текст как стартовую политику. Прежде чем создавать файлы, адаптируй названия папок к реально существующей структуре vault и покажи пользователю результат.

```markdown
# Правила работы с хранилищем

## Структура

- `Входящие/` — сырьё: клипы, обрывки и необработанные материалы.
- `Заметки/` — обработанные материалы, на которые можно ссылаться.
- `Гайды/` — инструкции для людей.

## Можно без дополнительного согласования

- Читать и искать по файлам.
- Создавать новые файлы во `Входящие/`.
- Предлагать правки текстом в ответе.

## Нужна явная просьба пользователя

- Переименовывать или перемещать файлы.
- Переписывать существующие заметки в `Заметки/`.
- Удалять что-либо.
- Вносить изменения в репозиторий или отправлять их на GitHub.

## Формат новой заметки

Первая строка — заголовок. В конце добавь раздел `## Связано` со ссылками `[[...]]` только на существующие заметки.
```

При наличии `AGENTS.md` или `CLAUDE.md` не заменяй их шаблоном. Сохрани существующие полезные правила и предложи точечный патч.
