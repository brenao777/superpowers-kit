# Security policy

Не публикуйте в issue или pull request пароли, OAuth-токены, SSH-ключи, содержимое `.env`, device codes или конфигурации с секретами.

Для сообщения об уязвимости используйте приватный канал владельца репозитория. До появления публичного контакта не создавайте публичный issue с деталями уязвимости.
